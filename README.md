# 🚀 ClientHub CRM

A modern CRM dashboard built with **Next.js, TypeScript, and React Query**.  
This application allows managing clients and deals with filtering, sorting, pagination, and CRUD operations.

---

## ✨ Features

- 📋 Clients management (Create, Read, Update, Delete)
- 🔍 Search clients by name, email, or company
- 🎯 Filter clients by status
- ↕️ Sorting (name, date, etc.)
- 📄 Pagination
- 💼 Deals management module
- ⚡ Optimized rendering with useMemo
- 📱 Responsive layout with sidebar

---

## 🛠 Tech Stack

### Frontend
- Next.js (App Router)
- React
- TypeScript

### State & Data
- React Query (server state)
- useState, useMemo (client state)

### UI & Styling
- Tailwind CSS
